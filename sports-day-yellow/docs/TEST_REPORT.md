## หมายเหตุ / สิ่งที่ยังไม่ได้ทดสอบ
- **ยังไม่ได้ทดสอบกับ Supabase project จริง** (ไม่มี credentials) — SQL ทดสอบบน PostgreSQL ผ่าน PGlite โดยจำลอง `auth.jwt()`, roles และ publication;
  หน้าล็อกอิน, Realtime ข้ามเครื่อง และการบันทึกพร้อมกันจริง (2 connection) ควรทดสอบอีกครั้งหลังเชื่อม Supabase ตามขั้นตอนใน README
- กล่องพิมพ์ของระบบปฏิบัติการไม่ได้เปิดจริงระหว่างทดสอบ (ตรวจเนื้อหาที่จะพิมพ์แทน) — ควรลองพิมพ์ 1 หน้าบนเครื่องที่ใช้จริง

## Checklist ทดสอบหลังเชื่อม Supabase (ทำเองได้ใน 5 นาที)
1. เปิดเว็บ 2 เครื่อง (หรือ 2 เบราว์เซอร์) ล็อกอินคนละบัญชี
2. เครื่อง A จัดตัว 2 คนลง "บอลยักษ์" → เครื่อง B ต้องเห็นภายใน 1–2 วินาทีโดยไม่กดรีเฟรช
3. ทั้งสองเครื่องเปิดหน้าต่างจัดตัวกีฬาเดียวกัน เลือกคนเดียวกัน กดบันทึกพร้อมกัน → ต้องได้รายการเดียว (อีกเครื่องขึ้น "ข้าม 1 คนที่สมัครแล้ว")
4. ปิดเว็บแล้วเปิดใหม่ → ข้อมูลยังอยู่
5. ดูเมนู ประวัติการเปลี่ยนแปลง → เห็นอีเมล/ชื่อผู้บันทึกถูกต้อง

# คู่มือใช้งานสำหรับเจ้าหน้าที่ — ระบบจัดตัวนักกีฬาสีเหลือง 2569

## เริ่มต้น
1. เปิดลิงก์ระบบ → เข้าสู่ระบบด้วยอีเมล/รหัสผ่านที่ได้รับ (ถ้าเป็นโหมด Demo จะไม่มีหน้านี้)
2. ครั้งแรกระบบจะถาม **ชื่อผู้บันทึก** — ใส่ชื่อตัวเอง เพื่อให้ประวัติบอกได้ว่าใครเป็นคนแก้ไข (เปลี่ยนได้ที่มุมขวาบน)
3. เมนูหลัก: **แดชบอร์ด · จัดการนักกีฬา · รายงาน** (บนมือถืออยู่แถบล่างจอ)

> มุมขวาบนมีจุดสถานะ: 🟢 ซิงก์แล้ว · 🟡 กำลังซิงก์ · ⚪ ออฟไลน์ · 🔴 ซิงก์ไม่สำเร็จ — กดปุ่ม ⟳ เพื่อโหลดข้อมูลล่าสุด

## จัดตัวนักกีฬา (งานหลัก)
1. ที่แดชบอร์ด กดปุ่ม **"จัดตัวนักกีฬา"** (ปุ่มบนการ์ดกีฬา หรือปุ่มเหนือการ์ด)
2. เลือก **ประเภทกีฬา**
3. ติ๊กชื่อสมาชิกได้หลายคน (มีช่องค้นหาชื่อ/รหัส) — คนที่สมัครกีฬานี้แล้วจะขึ้น **✓ สมัครแล้ว** และติ๊กซ้ำไม่ได้
4. ดูตัวเลข **สมัครแล้ว / เลือกแล้ว / เป้าหมาย** ด้านบน และ "หลังบันทึก X / Y คน" ด้านล่าง
5. กด **"บันทึก (เพิ่ม N คน)"** → ขึ้นข้อความยืนยันมุมล่าง และรายชื่อขึ้นบนการ์ดกีฬาทันที
6. ถ้าจำนวนจะ **เกินเป้าหมาย** ระบบจะถามยืนยันก่อน — กด "ยืนยันเพิ่มเกินเป้าหมาย" เฉพาะเมื่อได้รับอนุญาต

สมาชิก 1 คน ลงได้หลายกีฬา แต่ลงกีฬาเดียวกันซ้ำไม่ได้ · ไม่จำเป็นต้องให้ทุกคนลงแข่ง

## ดู/แก้ไขรายบุคคล
- กด **ชื่อสมาชิก** (หรือปุ่ม "จัดการ") ในตาราง → เห็นกีฬาทุกประเภท กด **+ เพิ่ม** หรือ **× ยกเลิก** ได้เลย พร้อมประวัติของคนนั้น
- ตัวกรองเหนือตาราง: ทั้งหมด / ลงแข่งขันแล้ว / ยังไม่ได้ลงแข่งขัน / ลงแข่งขัน 1 ประเภท / มากกว่า 1 ประเภท

## การ์ดกีฬา
แต่ละการ์ดแสดง ผู้สมัคร X / เป้าหมาย, ยังขาดกี่คน, แถบความคืบหน้า และสถานะ:
**ยังไม่มีผู้สมัคร · กำลังรับสมัคร · ครบจำนวน (เขียว) · เกินจำนวนเป้าหมาย (ส้ม)**
- **ดูรายชื่อทั้งหมด** → รายชื่อเต็ม ยกเลิกรายคน ดาวน์โหลด CSV
- **พิมพ์รายชื่อ** → ใบรายชื่อ A4 พร้อมช่องลงชื่อ

## จัดการนักกีฬา (สำหรับผู้ดูแล)
| แท็บ | ทำอะไรได้ |
|---|---|
| สมาชิก | เพิ่มสมาชิกใหม่ (รหัสถัดไปอัตโนมัติ), แก้ไขชื่อ, ปิด/เปิดใช้งาน (ไม่ลบข้อมูลจริง — ปิดแล้วการสมัครของคนนั้นถูกยกเลิก) |
| ประเภทกีฬา | เพิ่มกีฬา, **แก้ชื่อ/จำนวนเป้าหมาย**, ปิด/เปิดใช้งานกีฬา |
| ย้ายกีฬา | เลือกสมาชิก → กีฬาเดิม → กีฬาใหม่ → ย้ายในขั้นตอนเดียว |
| ประวัติการเปลี่ยนแปลง | ดูว่าใคร ทำอะไร เมื่อไร ค้นหาและกรองได้ |
| รีเซ็ตข้อมูล | ยกเลิกการสมัครทั้งหมด (ต้องพิมพ์ RESET) — ข้อมูลสมาชิกและประวัติยังอยู่ครบ |

ทุกการยกเลิก/ปิดใช้งาน/รีเซ็ต จะมีหน้าต่างให้ยืนยันก่อนเสมอ

## รายงาน
- **สรุปภาพรวมสีเหลือง** (พิมพ์) — ตัวเลขสรุป ความคืบหน้าแต่ละกีฬา รายชื่อคนที่ยังไม่ลง
- **รายชื่อสมาชิกทั้งหมด** (พิมพ์ / CSV) — แต่ละคนลงกีฬาอะไรบ้าง
- **รายชื่อทุกประเภทกีฬา** (พิมพ์ หน้าละ 1 กีฬา / CSV)
- รายงานแยกแต่ละกีฬา (พิมพ์ / CSV)

ไฟล์ CSV เปิดด้วย Excel ได้ทันที ภาษาไทยไม่เพี้ยน · ต้องการ PDF ให้กดพิมพ์แล้วเลือก "Save as PDF"

## ข้อควรรู้
- **โหมด Demo** (แถบสีส้มด้านบน): ข้อมูลอยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น เครื่องอื่นไม่เห็น — ใช้ทดลองเท่านั้น
- โหมดใช้งานจริง: ทุกเครื่องเห็นข้อมูลเดียวกันและอัปเดตอัตโนมัติ
- ถ้าบันทึกไม่สำเร็จ จะมีข้อความสีแดงบอกสาเหตุ เช่น "สมาชิกคนนี้สมัครกีฬาประเภทนี้อยู่แล้ว" หรือ "เชื่อมต่อฐานข้อมูลไม่ได้"

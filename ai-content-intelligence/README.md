# AI Content Intelligence Team (MVP)

แดชบอร์ดภาษาไทยสำหรับครีเอเตอร์/เพจข่าว: ดึงข่าวและเทรนด์จริง → ตัดข่าวซ้ำ → ให้คะแนน 100 → Top 10 → เลือก 5 → สคริปต์คลิปแนวตั้ง → Fact Check → ผู้ใช้อนุมัติ → บันทึกผลโพสต์และวิเคราะห์

สถาปัตยกรรม บทบาท AI โครงสร้างข้อมูล และ workflow อยู่ใน [ARCHITECTURE.md](ARCHITECTURE.md)

## วิธีรัน

```bash
npm install
npm start
```

เปิด http://127.0.0.1:5180 แล้วกด **เริ่มรอบค้นหา** (ต้องใช้ Node 20 ขึ้นไป และต้องต่ออินเทอร์เน็ตเพื่อดึงฟีด)

ถ้าจะเปิดใช้ AI: คัดลอก `.env.example` เป็น `.env` แล้วใส่ `ANTHROPIC_API_KEY` จากนั้นรีสตาร์ต ข้อมูลทั้งหมดเก็บอยู่ที่ `data/db.json`

### เชื่อมกับ AI Content Factory

1. ใน Content Factory ไปที่ **ตั้งค่า → การเชื่อมต่อ** สร้างโทเค็น (แสดงครั้งเดียว)
2. ใส่ใน `.env` ของโปรแกรมนี้: `FACTORY_URL=http://localhost:8080` และ `FACTORY_TOKEN=acf_it_...` (ห้ามวางโทเค็นในแชทหรือ commit) แล้วรีสตาร์ต
3. ได้ 3 อย่าง:
   - ถ้าไม่มี `ANTHROPIC_API_KEY` ทุกงาน AI จะใช้ AI ของ Factory (Gemini หรือ Ollama) ตามโควตาของ Factory — ถ้า Factory ตั้งให้ถามก่อนใช้ AI ที่อาจมีค่าใช้จ่าย หน้าเว็บจะถามยืนยันก่อน และการประชุมประจำวันอัตโนมัติจะไม่รัน (ไม่มีคนกดยืนยัน) เว้นแต่ใช้ Ollama
   - หน้า **ประชุมทีม AI** มีการประชุมวิเคราะห์วิดีโอจาก Factory: Video Analyst → Fact Checker → Editor → Performance Analyst → Content Director ทีมเห็นคำพูดที่มีเวลากำกับและผลวิเคราะห์ที่ Factory วัดได้ (ไม่ได้ดูภาพเอง) — ข้ออ้างที่ Fact Checker ให้ "เสี่ยง" ทำให้มติเป็น "ต้องแก้" เสมอ
   - งานที่อนุมัติแล้วกด **ส่งสคริปต์ไป Content Factory** ได้ จากนั้นในตัวแก้ไขวิดีโอของ Factory ใช้แผง "สคริปต์จาก Content Intelligence" ใส่เป็นข้อความบนจอ

## สถานะความสามารถ

| ความสามารถ | สถานะ | หมายเหตุ |
|---|---|---|
| ดึงข่าวจาก RSS จริง: Google News TH, Google Trends TH, BBC ไทย, ไทยรัฐ, มติชน, ข่าวสด (ประชาไทปิดไว้เป็นค่าเริ่มต้น) | ✅ ใช้ได้ | เพิ่ม/แก้/ทดสอบฟีดได้ในหน้า Settings |
| บันทึกลิงก์ วันที่เผยแพร่ วันที่ค้นพบ และวันที่เกิดเหตุ (แยกกัน) | ✅ ใช้ได้ | ฟีดไม่ให้เวลาเกิดเหตุ ผู้ใช้ต้องกรอกเอง ถ้าไม่กรอกจะแสดงว่า "ยังไม่ทราบ" |
| ตัดข่าวซ้ำ รวมข่าวเดียวกันจากหลายแหล่ง | ✅ ใช้ได้ | เทียบหัวข้อด้วย character trigram |
| แยกข่าวที่ยืนยันแล้ว / ยังไม่ยืนยัน / ความคิดเห็น | ✅ ใช้ได้ | ใช้กฎ (นับว่ามีกี่แหล่ง และดูคำบ่งชี้ว่าเป็นความเห็นหรือข่าวลือ) ผู้ใช้แก้เองได้ |
| คะแนน 100 (สดใหม่/สำคัญ/ความสนใจ/เหมาะกับเพจ/ความเสี่ยง) พร้อมเหตุผล | ✅ ใช้ได้ | ปรับน้ำหนักได้ |
| Top 10 และแนะนำ 5 ประเด็น | ✅ ใช้ได้ | |
| ค้นหาและกรองตามหมวด คะแนน สถานะ แหล่งข่าว วันที่ และการยืนยัน | ✅ ใช้ได้ | |
| สคริปต์ 30–90 วิ (Hook, Storyboard, แคปชั่น, แฮชแท็ก, ภาพประกอบ, ตัดต่อ, ลิขสิทธิ์) | ⚠️ ไม่มี key = แม่แบบ / มี key = AI | แม่แบบสร้างโครงจากหัวข่าวจริง ต้องเขียนเนื้อหาเอง |
| Fact Check ด้วยกฎ (ลิงก์ วันที่ จำนวนแหล่ง ตัวเลขในสคริปต์ คำบอกเวลา ความเสี่ยง) | ✅ ใช้ได้ | |
| Fact Check ข้ออ้างด้วย AI | 🔑 ต้องตั้งค่า API key | เทียบได้เฉพาะหัวข้อและสรุปจากฟีด |
| วิเคราะห์ Top N ด้วย AI | 🔑 ต้องตั้งค่า API key | |
| ขั้นอนุมัติ: ต้องผ่าน Fact Check ก่อน ถ้ามีข้อที่ไม่ผ่านต้องกรอกเหตุผล override | ✅ ใช้ได้ | บันทึกลง audit log |
| ผลโพสต์: กรอกเองหรือนำเข้า CSV แล้วเทียบกับค่าเฉลี่ยโพสต์ก่อนหน้า | ✅ ใช้ได้ | สรุปด้วย AI ต้องตั้งค่า key |
| ส่งออก CSV/JSON (ข่าว งาน ผลโพสต์ audit log), ประวัติรอบค้นหา, audit log | ✅ ใช้ได้ | ไฟล์ CSV ใส่ BOM ไว้ให้ Excel อ่านภาษาไทยได้ |
| คลัง Prompt ผู้เชี่ยวชาญ 6 คน + Prompt ประชุม + กติกาคุณภาพ (หน้า "คลัง Prompt ผู้เชี่ยวชาญ") | ✅ ใช้ได้ | ระบบประชุมอัตโนมัติใช้ข้อความชุดเดียวกัน (`server/experts.js`) |
| ประชุมทีม AI อัตโนมัติ: เรียกผู้เชี่ยวชาญ 5 คนตามลำดับ → Content Director สรุปข้อขัดแย้ง ลงมติ มอบหมายงาน → สร้างงานร่างใน Dashboard | 🔑 ต้องตั้งค่า API key | ทดสอบ orchestration ด้วย Claude จำลองแล้ว แต่**ยังไม่ได้ทดสอบกับ Claude API จริง** · ใช้ Claude 6 ครั้งต่อการประชุม |
| ประชุมอัตโนมัติทุกวัน (ค้นหาข่าวรอบใหม่ แล้วประชุม) | 🔑 API key + ตั้งเวลาใน Settings | เซิร์ฟเวอร์ต้องเปิดอยู่ตอนถึงเวลา |
| รอบค้นหาอัตโนมัติ | 🔑 ตั้งค่า `AUTO_RUN_MINUTES` | |
| อ่านเนื้อข่าวเต็มหรือค้นเว็บเพิ่มเพื่อตรวจข้อเท็จจริง | ❌ ยังไม่ทำ | |
| ดึงยอดวิวอัตโนมัติจาก Facebook/TikTok/YouTube | ❌ ยังไม่ทำ | ต้องใช้ OAuth และผ่าน app review ของแต่ละแพลตฟอร์ม |
| โพสต์อัตโนมัติ | ❌ ตั้งใจไม่ทำ | ระบบไม่โพสต์อะไรออกไปเอง |
| ผู้ใช้หลายคน / ล็อกอิน | ❌ ยังไม่ทำ | ตอนนี้ใช้คนเดียวบนเครื่อง (bind 127.0.0.1) ถ้าเปิดให้เครื่องอื่นเข้าได้ ให้ตั้ง `ADMIN_TOKEN` |

## ข้อมูลจำลอง

เพิ่มหรือลบได้ที่หน้า Settings ทุกรายการติดป้าย "ข้อมูลจำลอง" ไม่มีลิงก์ ไม่ถูกส่งให้ AI และอนุมัติเพื่อเผยแพร่ไม่ได้

## โครงสร้างไฟล์

```
server/index.js    API + Content Director (orchestration)
server/sources.js  Trend Hunter (RSS/Atom/Google Trends parser)
server/pipeline.js กฎ: dedup, หมวด, การยืนยัน, คะแนน, fact-check, แม่แบบสคริปต์, สถิติผลโพสต์
server/agents.js   Claude: Analyst, Producer, Fact Checker, Performance Analyst
server/experts.js  Prompt ผู้เชี่ยวชาญ 6 คน, Prompt ประชุม, กติกาคุณภาพ, schema ผลลัพธ์
server/meeting.js  ประชุมทีม AI: เรียกตามลำดับ → ประธานลงมติ → บังคับกติกาในโค้ด → บันทึก
server/db.js       ฐานข้อมูล JSON (atomic write) + audit log
server/seed.js     ข้อมูลจำลอง
public/            UI (vanilla JS ไม่ต้อง build)
```
